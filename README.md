# Loja G&G Soluções de Medição

Vitrine de produtos da G&G: manômetros, termômetros, reguladores de pressão Famabras, maçaricos e equipamentos para extração de chopp. O cliente escolhe o produto e o botão abre o WhatsApp (11) 92540-0775 com o pedido escrito.

- `index.html`: a página inteira, com a lista de produtos dentro dela.
- `img/`: fotos dos produtos (do portfólio Famabras).

## Publicar no GitHub Pages

Settings → Pages → Source: "Deploy from a branch" → Branch `main`, pasta `/ (root)` → Save.
